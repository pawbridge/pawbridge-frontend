# Material Symbols SVG

Google [material-design-icons](https://github.com/google/material-design-icons) 저장소의 Outlined 아이콘이다(Apache-2.0, `LICENSE`).
화면에서 쓰던 글꼴 설정과 같은 `opsz 24`, `wght 400`, `GRAD 0` 모양이며, `-fill`은 채운 모양(`FILL 1`)이다.

새 아이콘은 같은 커밋에서 받는다.

```sh
curl -fo <name>.svg https://raw.githubusercontent.com/google/material-design-icons/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg
curl -fo <name>-fill.svg https://raw.githubusercontent.com/google/material-design-icons/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web/<name>/materialsymbolsoutlined/<name>_fill1_24px.svg
```
